## Запуск в IntelliJ IDEA

1. Выберите **File → Open** и откройте папку `java-practice-2`.
2. В **File → Project Structure → Project SDK** выберите установленный **JDK 17 или новее**. На этом компьютере установлен `openjdk-27`.
3. Дождитесь индексации, выберите конфигурацию **ПР 08…**, **ПР 09…**, **ПР 10…**, **ПР 11…**, **ПР 13…** или **ПР 14…** в верхней панели и нажмите зелёную кнопку **Run**.
4. Вводите значения в консоли **Run**. Для рекурсивных задач подсказки не печатаются; примеры ввода приведены ниже.

В `.run` сохранены 16 готовых конфигураций, рабочая папка — корень проекта. Внешние библиотеки не нужны, кодировка — UTF-8. Для получения прямо из GitHub можно использовать **Get from VCS** / **Clone Repository** и адрес этого репозитория.

Запуск без IDE из корня проекта:

```sh
javac --release 17 -encoding UTF-8 -d out @sources.txt
java -cp out practice0910.Main09
```

В последней команде замените класс на нужный из таблиц.

## Работа 11 — все задания

| Задание | Запускаемый класс | Пример ввода |
|---|---|---|
| 1. Дата получения и сдачи | `practice11.Task01` | `Игнатов`, затем `09.11.2026 10:00` |
| 2. Сравнение дат | `practice11.Task02` | `01.01.2000 00:00` |
| 3. Дата рождения Student | `practice11.Task03` | `SHORT`, `MEDIUM` или `FULL` |
| 4. Объекты Date и Calendar | `practice11.Task04` | `2024 2 29`, затем `12 30` |
| 5. Производительность коллекций | `practice11.Task05` | Ввод не нужен |

Даты вводятся в формате `dd.MM.yyyy HH:mm`, часовой пояс — Москва. Время получения в примере и дата рождения студента — демонстрационные данные. Время сдачи определяется при запуске. В измерении коллекций сравниваются добавление в конец, вставка и удаление по среднему индексу и поиск `contains`; после прогрева берётся медиана семи серий.

## Работа 13 — все задания

| Задания | Запускаемый класс | Ввод |
|---|---|---|
| 1–6: демонстрация String, Person, Address, Shirt, телефонов и цепочки слов | `practice13.Main13` | Не нужен |
| 1: отдельный запуск методов String | `practice13.StringTask` | Не нужен; строку можно передать аргументом |
| 6: чтение слов из файла по условию | `practice13.WordChain` | `data/words.txt` |

Для задания 6 имя файла вводится в консоль Run после запуска. Файл должен быть в UTF-8, слова разделяются пробельными символами. В примере получается `Киев Вена Амстердам Мельбурн Нью-Йорк`. При невозможности составить цепочку программа выводит сообщение.

Для Address реализованы разбор через `split()` и через `StringTokenizer`, каждый проверяется на четырёх адресах. Пустые поля сохраняются. Все 11 строк рубашек из условия преобразуются в массив `Shirt[]`.
